40 терминов по специальности

Специалист компьютерных сетей и комплексов

1. IP-адрес

Уникальный адрес устройства в сети.

2. DNS

Система преобразования доменных имён в IP-адреса.

3. Сервер

Компьютер, предоставляющий ресурсы другим устройствам.

4. Клиент

Устройство или программа, использующая ресурсы сервера.

5. Маршрутизатор

Устройство для передачи данных между сетями.

6. Коммутатор

Устройство для соединения компьютеров внутри сети.

7. Локальная сеть (LAN)

Сеть внутри одного здания или организации.

8. Глобальная сеть (WAN)

Сеть, объединяющая устройства на больших расстояниях.

9. Протокол

Набор правил передачи данных.

10. TCP/IP

Основной набор сетевых протоколов интернета.

11. HTTP

Протокол передачи веб-страниц.

12. HTTPS

Защищённая версия протокола HTTP.

13. FTP

Протокол передачи файлов.

14. VPN

Технология защищённого соединения через интернет.

15. Firewall

Средство защиты сети от угроз.

16. MAC-адрес

Физический адрес сетевого устройства.

17. Wi‑Fi

Беспроводная технология передачи данных.

18. Кабель витая пара

Основной сетевой кабель Ethernet.

19. Ethernet

Технология проводных локальных сетей.

20. Шлюз

Устройство для соединения разных сетей.

21. DHCP

Протокол автоматической выдачи IP-адресов.

22. Ping

Команда проверки связи между устройствами.

23. Хост

Любое устройство, подключённое к сети.

24. Домен

Уникальное имя сайта или сети.

25. Облачные технологии

Хранение и обработка данных через интернет.

26. Виртуализация

Создание виртуальных машин и систем.

27. Linux

Популярная серверная операционная система.

28. Windows Server

Серверная операционная система Microsoft.

29. База данных

Организованное хранилище информации.

30. SQL

Язык управления базами данных.

31. Резервное копирование

Создание копий данных для восстановления.

32. Антивирус

Программа для защиты от вредоносного ПО.

33. Кибербезопасность

Защита систем и сетей от атак.

34. Трафик

Объём передаваемых данных в сети.

35. Сетевой адаптер

Устройство подключения компьютера к сети.

36. Топология сети

Схема расположения сетевых устройств.

37. Proxy-сервер

Промежуточный сервер между клиентом и интернетом.

38. Дата-центр

Помещение для размещения серверов.

39. Сетевой пакет
